## Notes for the Harvest Wave

- **Project Gutenberg** sources (Bullock 13487) provide **clean plain text + HTML** — no OCR cleanup required. Prefer these.
- **Internet Archive** sources provide PDF + DjVu + plaintext OCR; quality varies. Kappeler and Straub OCR are clean per spot-checks; Schmidt's may need more cleanup.
- **EUVS Digital Collection** (`archive.org/details/vintage-cocktail-books-euvs`) is a single-uploader bulk collection — many pre-1929 books are bundled here. Worth a dedicated pass to inventory which exact PDFs land where.
- For US public-domain certainty, every book listed above was **published before 1929** — the bright-line rule. No renewal-search legwork required.
- Tom Bullock's foreword by George Herbert Walker is gold for the contributor_story field; quote the foreword directly when surfacing the collection in the UI.
